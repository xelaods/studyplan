# StudyPlan（時間割）

江戸川大学専用の時間割アプリです（SwiftUI、iOS 17 以降）。
エドポタの「学生時間割表」や Web シラバスから授業を読み取り、選ぶだけで時間割に入れられます。iPhone 純正アプリのような見た目で、ホーム画面・ロック画面のウィジェット付き。

## できること

| タブ | 内容 |
|---|---|
| 今日 | 今日の日付と学期、授業中（残り時間とバー）・次の授業、今日の授業の一覧、次の授業日、時間外の授業 |
| 時間割 | 月〜金（土曜も可）× 1〜5限（7限まで可）の表。今日の列と授業中のコマを強調。空いているマスをタップすると、取得した授業からその曜日・時限のものを選ぶだけで入る。前期・後期の切り替え |
| 通学 | スクールバス × 電車 × 時間割の乗り継ぎ。1限に間に合う便（ギリ・遅刻の表示）と帰りの便、次のスクールバス（先発・次発・次々発）、ダイヤ判定つきのバス時刻表、大学のバス時刻表ページ |
| 授業 | 曜日ごとの授業一覧、取得した授業の一覧（検索して追加）、右スワイプで必修・選択の切り替え、左スワイプで削除 |
| 設定 | 表示する学期（自動／前期／後期）、土曜日、時限数、時限の時間、ウィジェット連携、エドポタからのログアウト |

色は「必修＝赤、それ以外＝青」の2色だけです。授業の詳細か、授業タブの右スワイプで切り替えられます（同じ授業名はまとめて変わります）。授業の詳細では、教室・担当教員・時間割コード、欠席・遅刻の回数（アプリ内のメモ）、メモも変えられます。

### 通学（スクールバス × 電車）

Scriptable の乗継ウィジェットと同じ考え方を、アプリの時間割と組み合わせています。

- スクールバスの時刻は大学のサイネージページ（bus.html）から取得し、ページと同じ方法でその日のダイヤ（Aダイヤ・特別ダイヤ・運行なし）を判定
- 電車は Yahoo!乗換案内で、バスに間に合う電車（通学）・バスに乗ったあとの電車（帰宅）を検索
- 1限の前は「通学」（授業開始 − 徒歩 − バス乗車 までに出るバスが「ギリ」）、授業のあとは「帰宅」、残りは次に授業がある日の通学表
- 自宅の駅・乗り換え時間などは「通学」タブ左上の設定で変更（初期値は舞浜）

### 授業の取り込み方

1. 「授業」タブ（または時間割の ＋）→「エドポタから取り込む」
2. アプリ内のブラウザでエドポタにログイン（ID・パスワードはアプリに保存しません）
3. 上のメニュー「履修・時間割」→「学生時間割表」を開く
4. 下の「この画面から授業を読み取る」→ 見つかった授業にチェックを入れて「時間割に追加」

前期・後期の表が両方ある画面でも、それぞれの学期として読み取ります。読み取った授業は「取得した授業」に残るので、あとで空きコマをタップしたときの候補にも出てきます。
ログインせずに探すときは「Webシラバスで探す」から検索結果の一覧を開いて、同じように読み取れます。

### 時限（江戸川大学）

| 時限 | 時間 |
|---|---|
| 1限 | 9:00〜10:40 |
| 2限 | 10:50〜12:30 |
| 3限 | 13:10〜14:50 |
| 4限 | 15:00〜16:40 |
| 5限 | 16:50〜18:30 |

6・7限は目安の時間なので、設定の「時限の時間」で変えられます。

### ウィジェット

| ウィジェット | サイズ |
|---|---|
| 次の授業 | 小・ロック画面（長方形・円・1行）。授業中は残り時間 |
| 今日の授業 | 中・大。終わったら次の授業日 |
| 時間割 | 大。1週間の表 |
| 通学 | 中・大。バスと電車の乗り継ぎ（ウィジェット自身が15分ごとに調べ直す） |

署名に App Group が入っていればそれで共有します。入っていない場合（普段の署名ツール）は、Shift Note・MoneyPlan と同じように**カレンダーの 2001年1月3日に時間割のメモを1件だけ**保存してウィジェットに渡します。初回は「設定 › ウィジェット › カレンダーへのアクセスを許可」をタップしてください。

## IPA の作り方（Mac 不要）

`main` に push すると、GitHub Actions（`.github/workflows/ios.yml`）が自動でビルドします。手動で動かすときは **Actions** タブ →「iOS Build」→「Run workflow」。

1. 完了した実行を開き、下の **Artifacts** から `StudyPlan-unsigned-番号.ipa` をダウンロード
2. 普段使っている署名ツールで署名してインストール

ビルドの途中で、時間割表・シラバス一覧の読み取りと時間の計算のテストも行います。見本データでの各画面のスクリーンショットは `ci-screenshots` ブランチに置かれます。

## 構成

```
Shared/            データ・読み取り・時間の計算・ウィジェットの表示（アプリとウィジェットで共通）
StudyPlan/         アプリ本体（SwiftUI）。エドポタの読み取りは Views/ImportView.swift
StudyPlanWidget/   ウィジェット（WidgetKit）
StudyPlanTests/    読み取りと時間の計算のテスト
tools/icon.py      アイコンを作るスクリプト
project.yml        XcodeGen の設定（Xcode プロジェクトはビルド時に作る）
```
